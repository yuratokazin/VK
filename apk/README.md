Чтобы компьютер смог **принимать** файлы, выполните следующее:

#### Включите «Общий доступ к файлам» в KDE

Это самый быстрый способ активировать нужный сервис:

1. Откройте **Параметры системы**.
2. Перейдите в раздел **Bluetooth** -> **Адаптер** (Galaxy A21s)
3. Нажмите кнопку **«Настроить»** (она может быть внизу или в меню конфигурации адаптера).
4. В появившемся окне установите галочку При получении файлов **«Всегда принимать»**.
